## Ева-стиль 1.5.1

### Изменено
- В зарплатах сотрудников тип операции «Штраф» переименован в «Вычет» (старые записи мигрируют автоматически)
- Оплата администратора: вместо отметки смены и тарифов по дням недели — ручной ввод ЗП за каждый день в табеле; блок тарифов админов убран из настроек

### Исправлено
- Интерфейс на старых Windows (WebView2 109 / Win 7–8): стили снова читаемые — Tailwind v3 вместо v4 (без oklch)
