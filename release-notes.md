## Ева-стиль 1.5.0

### Добавлено (бета)
- AI-помощник DeepSeek: чат в шапке, ответы по справке и данным салона
- Ключ API и переключатель записи — «Владелица → Безопасность» (запись по умолчанию выкл., изменения с подтверждением)
- Помощник может открывать вкладки/разделы, выбирать дату журнала, открывать CrashLogs
- При включённой записи — визиты, солярий, доп. операции, тарифы, прайс сырья (whitelist)
